# Kentik Cloud Export provider

The Kentik Cloud Export provider manages Kentik cloud exports, which import flow logs and metadata from
AWS, Azure, Google Cloud and Oracle Cloud Infrastructure. It uses the Kentik `cloud_export/v202506` gRPC API.

Upgrading from 0.4.x? Read the [upgrade guide](https://github.com/kentik/terraform-provider-kentik-cloudexport/blob/master/docs/UPGRADING.md):
existing configurations and state keep working, IBM Cloud exports are no longer supported by the API, and
`bgp` and `aws.multiple_buckets` are deprecated and ignored.

## Example usage

```terraform
terraform {
  required_providers {
    kentik-cloudexport = {
      source = "kentik/kentik-cloudexport"
    }
  }
}

# Credentials are usually supplied through KTAPI_AUTH_EMAIL and KTAPI_AUTH_TOKEN.
provider "kentik-cloudexport" {
  # email  = "john@acme.com"
  # token  = "..."
  region = "EU" # US (default) or EU; or set endpoint = "host:port"
}
```

Credentials can also be supplied with environment variables:

```bash
export KTAPI_AUTH_EMAIL="john@acme.com"
export KTAPI_AUTH_TOKEN="token"
export KTAPI_REGION="EU" # optional, defaults to US
```

## Endpoint selection

The provider talks to `grpc.api.kentik.com:443` by default. The first of these settings that is set wins:

1. `endpoint` (`KTAPI_ENDPOINT`): a gRPC `host:port`, always over TLS.
2. `apiurl` (`KTAPI_URL`): a legacy base URL such as `https://api.kentik.eu`, mapped to `grpc.api.kentik.eu:443`.
3. `region` (`KTAPI_REGION`): `US` (`grpc.api.kentik.com:443`) or `EU` (`grpc.api.kentik.eu:443`).
